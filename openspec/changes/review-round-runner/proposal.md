# review-round-runner

## 問題

對抗審查迴圈目前是一堆散在 `/tmp` 的臨時指令。每輪要手動做四件事：貼約束、取快照、
比對快照、存回覆。手動流程的問題不是麻煩，是**它可以安靜地做錯**——
實際使用的快照指令只涵蓋 tracked 檔案，十九輪都沒發現。

## 提案

一個零外部相依的 CLI，把一輪審查變成一個指令。它負責**證據**，不負責判斷：

- 送出前後對 repository 取完整性快照，**涵蓋 tracked 與 untracked**
- 自動加上約束區塊，不依賴人每次記得貼
- 背景執行並歸檔（prompt 與 reply 成對保存，附輪次編號）
- 工作樹不乾淨時拒絕開始

## 範圍

**做**：輪次管理、完整性快照與比對、約束注入、歸檔、狀態查詢。

**不做**：不判斷 blocker 真偽、不決定收斂線、不管理 Codex 安裝與登入、
**不放寬審查者的唯讀沙箱設定**。

## 為什麼現在做

rc.5 已簽核並進入 feature freeze，rc.6 仍會再跑這條迴圈；其他專案也會用。
而且那個快照漏洞現在已知 —— 知道了還用手動流程，等於明知有洞而繼續。
